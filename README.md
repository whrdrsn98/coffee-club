# Coffee Club — Telegram Mini App demo

Демонстрационный интерфейс кофейни: меню и фиксированный бонусный баланс.
Подключения к iiko, базы данных и реального начисления бонусов пока нет.

## Что внутри

- `index.html` — весь интерфейс, стили и демонстрационные данные.
- Адаптивная вёрстка для мобильного экрана.
- Категории меню.
- Заглушка бонусного баланса (245 бонусов).
- Поддержка Telegram Mini Apps SDK (`ready()` и `expand()`).

## Быстрый локальный просмотр на macOS

1. Распакуйте архив.
2. Откройте папку `coffee_club_demo`.
3. Дважды нажмите `index.html` — страница откроется в браузере.

Для проверки именно внутри Telegram нужен публичный HTTPS-адрес. Само открытие локального HTML-файла в браузере ещё не подключает его к Telegram.

## Публикация через GitHub Pages

1. Создайте репозиторий GitHub, например `coffee-club-demo`.
2. Загрузите в него `index.html`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, сохраните.
6. Дождитесь публикации. GitHub выдаст HTTPS-адрес сайта.

## Подключение к Telegram

1. Откройте Telegram и найдите `@BotFather`.
2. Создайте бота командой `/newbot`, задайте имя и username.
3. В BotFather откройте настройки созданного бота → Bot Settings → Menu Button → Configure menu button.
4. Укажите текст кнопки, например `Открыть меню`, и HTTPS-адрес GitHub Pages.
5. Откройте бота и нажмите кнопку меню.

На этом этапе бот открывает Mini App через кнопку меню. Автоматический ответ на `/start` и серверная логика бота будут отдельным следующим шагом.

## Как менять меню

В `index.html` найдите массив `drinks`:

```js
const drinks = [
  { name:"Капучино", category:"Кофе", size:"250 мл", price:190, emoji:"☕", desc:"Эспрессо, молоко и нежная пенка" }
];
```

Добавляйте или изменяйте объекты по тому же образцу. Допустимые категории сейчас: `Кофе`, `Холодные`, `Чай`.

Баланс меняется в строке:

```js
const bonusBalance = 245;
```

Не используйте реальные персональные данные гостей в демонстрационной версии.
